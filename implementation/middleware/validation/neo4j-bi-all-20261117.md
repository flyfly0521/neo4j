## 本轮实现

- 增加基于导入变量类型的 CALL 局部改写；保留 Neo4j CALL、UNION ALL 和原始返回列名，只替换通过守卫的分支。
- CALL 导入变量在内部 WITH 后继续传递；普通写语句和含嵌套写入的整条语句保持原文。
- 新增 `register_neo4j_index(..., parameters=...)`；参数值内联到定义，查询按值特化后才可命中。不同参数不会复用不适用的定义。
- 零初始化加稀疏 COUNT 物化注册为包含零计数的 OPTIONAL 定义；折叠多余聚合别名，补齐时间比较方向的规范化。
- 对新引入的匿名端点，规范化非 DISTINCT 的关系 COUNT，使原生 COUNT(rel) 能与等价节点计数索引匹配；保留 DISTINCT 和重复使用变量名的原有行为。
- NeuG 多候选目录触发 `unordered_map::at` 时逐个隔离候选重试；验证守卫保持开启。BI6 经此路径成功改写。
- 保留并返回注册过程中推断的 DDL，原有元数据回滚和 schema 变更标志仍有效。
